# LLM Research Portfolio

언어 모델의 사실성, 문맥 활용, 대조 디코딩, 파라미터 기반 지식 주입 연구를 정리한 개인 포트폴리오입니다.

## 구성

- 연구 방향
- CV 요약 및 핵심 역량
- 석사학위논문 및 RISS 링크
- 학력과 연구 연혁
- 연구·응용 프로젝트 경험
- 논문 및 학회 발표 자료

## 로컬 실행

Node.js 22 이상이 필요합니다.

```bash
npm install
npm run dev
```

프로덕션 정적 파일은 다음 명령으로 `out/` 폴더에 생성됩니다.

```bash
npm run build
```
